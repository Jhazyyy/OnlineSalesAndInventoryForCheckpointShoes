# Common Return/Exchange Reasons Reference

## Product Quality Issues
- Defective product
- Manufacturing defect
- Product damaged during shipping
- Product not as described
- Wrong product received
- Missing parts or accessories
- Product malfunction

## Size/Fit Issues (Shoes)
- Size too small
- Size too large
- Uncomfortable fit
- Width issues
- Arch support inadequate

## Customer Preference
- Changed mind
- Found better price elsewhere
- No longer needed
- Ordered wrong item/color
- Ordered duplicate by mistake

## Upgrade/Downgrade
- Want different model
- Want upgraded version
- Want different color/style
- Want different brand

## Other
- Gift return (no longer needed)
- Quality not meeting expectations
- Allergic reaction to materials
- Doctor recommendation (orthopedic issues)

---

## Exchange Types

### Product Exchange
- Same product, different size
- Same product, different color
- Different product, same price range

### Refund Exchange
- Full refund requested
- Partial refund (damaged/used)
- Store credit instead of refund

### Upgrade Exchange
- Exchange for more expensive model
- Exchange for premium version
- Additional payment required

---

## Return Policy Guidelines

### Timeframe
- Standard returns: 30 days from purchase
- Defective products: 90 days warranty
- Worn/used shoes: Not eligible (unless defective)

### Condition Requirements
- Original packaging required
- All tags and labels attached
- Unworn condition
- No signs of use (except for defect inspection)

### Exceptions
- Clearance/final sale items
- Custom orders
- Gift cards
- Intimate apparel (hygienic reasons)

---

## Processing Timeline

1. **Ticket Created**: Immediately
2. **Initial Review**: 1-2 business days
3. **Approval Decision**: 2-3 business days
4. **Return Shipping**: 5-7 business days
5. **Inspection**: 1-2 business days
6. **Refund/Exchange**: 3-5 business days

**Total Estimated Time**: 12-19 business days

---

## Return Instructions for Customers

### Step 1: Create Return Ticket
- Navigate to Sales > Exchanges
- Select the order
- Choose return reason
- Specify which items

### Step 2: Package Items
- Include all original packaging
- Remove all non-manufacturer tags
- Ensure shoes are clean and unworn
- Include any accessories

### Step 3: Ship Back
- Use provided return label (if applicable)
- Get tracking number
- Keep receipt until refund confirmed

### Step 4: Track Return
- Monitor ticket status in system
- Receive email notifications
- Check for refund confirmation

---

## Admin Guidelines

### Approving Returns
- Verify purchase date within policy
- Check item condition requirements
- Confirm reason is valid
- Review customer history

### Rejecting Returns
- Outside return window
- Item shows signs of wear
- Missing original packaging
- Not covered by policy
- Provide clear explanation to customer

### Processing Exchanges
- Verify new item availability
- Calculate price difference (if any)
- Update inventory accordingly
- Create new shipment for exchange item

---

## Notifications

### Customer Receives:
- Ticket created confirmation
- Status updates (approved/rejected)
- Refund processed notification
- Exchange shipped notification

### Admin Receives:
- New return ticket alert
- Approval required notification
- Item received notification
- Exception alerts (damaged returns)

---

## Best Practices

### For Staff:
1. Review tickets within 24 hours
2. Communicate clearly with customers
3. Document condition thoroughly
4. Process refunds promptly
5. Update inventory immediately

### For Customers:
1. Read return policy before ordering
2. Keep original packaging
3. Contact support with questions
4. Provide detailed return reason
5. Include order number in package
